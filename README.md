# ASWIN C S — Portfolio

A professional, responsive developer portfolio built with React, Vite, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Build for production

```bash
npm run build
```

The production files will be generated in `dist/`.

## Personalization

Main portfolio content is in `src/main.jsx`.
Visual styling is in `src/styles.css`.

The portfolio intentionally excludes the portfolio URL from the content.
